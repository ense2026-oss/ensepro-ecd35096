# นำเข้าข้อมูลเข้างาน/ออกงาน จากไฟล์ .txt ของเครื่องสแกนหน้า

เพิ่มฟังก์ชันอัปโหลดไฟล์ UDISKLOG (.txt) ที่ export จากเครื่องสแกนหน้า แล้วแปลงเป็นบันทึกเวลาเข้า-ออกในหน้า **บันทึกเวลา** โดยไม่ต้องเชื่อมต่อเครื่องโดยตรง


## จุดใช้งาน
- ปุ่ม "นำเข้าจากเครื่องสแกน" บนหน้า **บันทึกเวลา (Attendance)** ใกล้ชุดตัวกรอง สำหรับ admin/hr (หรือตามสิทธิ์ `attendance_*` ที่กำหนด)
- เปิด Dialog สองขั้นตอน: อัปโหลดไฟล์ → ตรวจสอบและยืนยันก่อนนำเข้า


## รูปแบบไฟล์ที่รองรับ (จากไฟล์ตัวอย่าง)
```text
UDISKLOG  version=3  date=...  firmware=...
No  Mchn  EnNo  Name  Mode  IOMd  DateTime
000001  C2637C580F223937  13  ณัฐวุฒิ ...  1073741824  2321  2026/07/01  05:59:32
```
- คั่นด้วย Tab, ข้าม 2 บรรทัดแรก
- ใช้ `EnNo` จับคู่กับ `face_scan_id` ของพนักงาน
- `DateTime` รูปแบบ `YYYY/MM/DD  HH:MM:SS` (ปี ค.ศ.)
- คอลัมน์ Mode/IOMd ในไฟล์นี้ไม่ได้ระบุเข้า/ออกที่เชื่อถือได้ จึงไม่ใช้

## ตรรกะการแปลงข้อมูล
1. จัดกลุ่มตาม พนักงาน + วันที่
2. เวลาแรกของวัน = เวลาเข้า, เวลาสุดท้ายของวัน = เวลาออก (ถ้ามีสแกนครั้งเดียว = เข้าอย่างเดียว)
3. เขียนลง `check_in_records` (source = `face_scan_file`, location = ชื่อ/SN เครื่อง, within_radius = true) ซึ่ง trigger เดิมจะสรุปต่อไปยัง `attendance_records` อัตโนมัติ
4. ถ้ามีบันทึกของพนักงาน+วันนั้นอยู่แล้ว: ค่าเริ่มต้นคือ "ข้าม" แต่มีตัวเลือก "เขียนทับ" ให้เลือกก่อนนำเข้า
5. ไม่แตะข้อมูลโอที (เวลาโอทีจริงยังมาจากปุ่มเข้า/ออก OT เหมือนเดิม)

## หน้าจอ (2 ขั้นตอน)
1. เลือกไฟล์ → แสดงสรุปก่อนนำเข้า: จำนวนบรรทัด, ช่วงวันที่, SN เครื่อง, จำนวนพนักงานที่จับคู่ได้, รายการรหัสที่ยังไม่ได้จับคู่ (พร้อมชื่อในเครื่อง เพื่อไปตั้งค่า face_scan_id)
2. กดยืนยัน → ประมวลผลเป็นชุด (batch) พร้อม progress bar และสรุปผล: เพิ่มใหม่ / เขียนทับ / ข้าม / ไม่พบพนักงาน
- บันทึกผลลง `face_scan_sync_logs` (sync_type = `file_import`) เพื่อดูย้อนหลังในแท็บประวัติ

## รายละเอียดทางเทคนิค
- Component ใหม่ `src/components/settings/FaceScanFileImport.tsx` (parse ฝั่ง client, อ่านไฟล์เป็น UTF-8)
- ใช้ supabase client เดิม: query `employees(id, face_scan_id)` แล้ว upsert/insert `check_in_records` เป็นชุดละ ~200 แถว
- ไม่มีการเปลี่ยนแปลงโครงสร้างฐานข้อมูล
