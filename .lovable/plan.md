# เพิ่มสิทธิ์ "เพิ่ม / ลบ" ให้แท็บตั้งค่าที่เป็นรายการ

## ปัญหา
ในไดอะล็อก "แก้ไข Role" แท็บย่อยของ "ตั้งค่า" ทุกตัวมีแค่สิทธิ์ **ดู** และ **แก้ไข** เท่านั้น แต่บางแท็บเป็นระบบจัดการรายการที่มีปุ่ม "เพิ่ม" และ "ลบ" จริง (เช่น จัดการแผนก, พื้นที่เข้างาน, กะการทำงาน, ประเภทการลา, วันหยุดบริษัท, ระบบอนุมัติ ฯลฯ) จึงควรเปิดสิทธิ์ เพิ่ม/ลบ ให้ครบ

## แนวทาง
แยกแท็บตั้งค่าออกเป็น 2 กลุ่มตามลักษณะการใช้งาน:

**กลุ่มจัดการรายการ → ดู / เพิ่ม / แก้ไข / ลบ**
- ตั้งค่า · จัดการแผนก (settings_affiliations)
- ตั้งค่า · พื้นที่เข้างาน (settings_locations)
- ตั้งค่า · สิทธิ์ผู้ใช้งาน (settings_roles)
- ตั้งค่า · ผู้ดูแลระบบ (settings_admins)
- ตั้งค่า · กะการทำงาน (settings_shifts)
- ตั้งค่า · ประเภทการลา (settings_leave_types)
- ตั้งค่า · วันหยุดบริษัท (settings_company_holidays)
- ตั้งค่า · ระบบอนุมัติ (settings_approval)

**กลุ่มฟอร์มตั้งค่า → ดู / แก้ไข (เหมือนเดิม)**
- ตั้งค่า · ข้อมูลบริษัท (settings_company)
- ตั้งค่า · ตั้งค่าเงินเดือน (settings_payroll)
- ตั้งค่า · ตั้งค่าโมดูล (settings_modules)
- ตั้งค่า · เครื่องสแกนหน้า (settings_facescan)
- ตั้งค่า · การแสดงผล (settings_display)

## ขั้นตอนทางเทคนิค

1. **`src/lib/settingsModules.ts`** — เพิ่มฟิลด์ `actions: ActionKey[]` ให้แต่ละรายการใน `SETTINGS_SUBMODULES` โดยกลุ่มจัดการรายการได้ `["view","add","edit","delete"]` และกลุ่มฟอร์มได้ `["view","edit"]`

2. **`src/components/settings/RolesSettings.tsx`** — เปลี่ยนการ map `SETTINGS_SUBMODULES` ให้ใช้ `m.actions` ที่กำหนดไว้แทนการ hard-code `["view","edit"]` ทุกตัว ทำให้ตารางสิทธิ์แสดงช่อง เพิ่ม/ลบ เฉพาะแท็บที่ควรมี

ส่วน `moduleConfigs` ยังครอบ `allActions` อยู่แล้ว ตารางจึงเรนเดอร์ปุ่ม เพิ่ม/ลบ ให้อัตโนมัติเมื่อ action นั้นอยู่ใน `mod.actions` และค่าจะถูกบันทึกลง `role_permissions` (can_add/can_delete) ตาม logic การ save เดิม โดยไม่ต้องแก้ migration หรือ schema

## หมายเหตุ
- ไม่ต้องแก้ฐานข้อมูล: คอลัมน์ `can_add` / `can_delete` มีอยู่แล้วในตาราง `role_permissions`
- การบังคับใช้สิทธิ์จริงภายในแต่ละหน้าตั้งค่า (ซ่อน/ปิดปุ่มเพิ่ม-ลบตามสิทธิ์) เป็นงานต่อยอดอีกขั้น แผนนี้โฟกัสที่การเปิดให้ "ตั้งค่า" สิทธิ์เพิ่ม/ลบ ได้ในไดอะล็อกก่อน ตามที่ร้องขอ
