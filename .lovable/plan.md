## เป้าหมาย
สร้างโปรแกรม **Bridge** ที่รันบน PC ในออฟฟิศ (เปิดทิ้งไว้) — เชื่อมเครื่องสแกนหน้า HIP CiF76S ผ่าน LAN ที่ `192.168.2.201` ดึงรายการสแกนแล้วส่งขึ้นระบบลงเวลาอัตโนมัติ ไม่ต้องเสียค่าเซิร์ฟเวอร์ ไม่ต้องเปิดพอร์ตเราเตอร์ ไม่ต้องแตะ ServerIP เดิมของเครื่อง

## ฝั่งระบบมีอะไรพร้อมแล้ว
Edge Functions ทั้งหมดที่ Bridge ต้องใช้ ติดตั้งและทำงานอยู่แล้ว:
- `facescan-bridge-poll` — Bridge ถามทุก 30 วิ เพื่อรับรายชื่อเครื่อง + รายชื่อพนักงาน + คำสั่งที่ค้างอยู่ (test / pull_logs / enroll)
- `facescan-ingest` — รับรายการสแกนแล้วบันทึกลงตารางลงเวลา
- `facescan-bridge-ack` — Bridge รายงานผลคำสั่งกลับ
- `facescan-token-create` — สร้าง Bridge Token (มีหน้า UI แล้วในแท็บ "Bridge Token")

จึงเหลือแค่สร้าง "ตัวโปรแกรม Bridge" ที่รันบน PC เท่านั้น

## ภาพรวมการไหลของข้อมูล
```text
[HIP CiF76S 192.168.2.201:4370]
        | LAN (node-zklib)
        v
[Bridge บน PC ออฟฟิศ]  --poll ทุก 30 วิ-->  facescan-bridge-poll
        |                                         (รับเครื่อง + คำสั่ง)
        | ดึง log การสแกน / ส่งผล
        v
   facescan-ingest  -->  ตาราง check_in_records  -->  หน้าลงเวลา
   facescan-bridge-ack (รายงานผล)
```

## วิธีเชื่อมเครื่อง (ทำไมใช้ port 4370 ไม่ใช่ 8272)
เครื่อง HIP CiF76S เป็นตระกูล ZK โดยทั่วไปเปิดโปรโตคอล ZK มาตรฐานที่ **TCP 4370** ไว้ จึงใช้ไลบรารี **node-zklib** (JavaScript ล้วน) คุยกับเครื่องได้โดยตรง — ไม่ต้องพึ่ง DLL ของ Windows ไม่ต้องลง driver พิเศษ ทำให้ติดตั้งบน PC เครื่องไหนก็ได้ที่มี Node.js

## สิ่งที่จะสร้าง

### 1) โฟลเดอร์ `facescan-bridge/` (โปรแกรมจริงที่รันได้)
- `bridge.js` — โปรแกรมหลัก:
  - อ่านค่าจาก `.env` (Bridge Token + URL ระบบ)
  - วนทุก 30 วิ: เรียก `facescan-bridge-poll` รับรายชื่อเครื่อง + คำสั่งค้าง
  - เชื่อมเครื่องผ่าน `node-zklib` ที่ IP เครื่อง:4370 ดึง attendance logs
  - กรองเฉพาะรายการใหม่ (เก็บเวลา cursor ล่าสุดต่อเครื่องไว้ในไฟล์ `state.json`)
  - แปลงเป็นรูปแบบ `{ enroll_number, datetime (ISO), verify_mode, in_out }` แล้วส่งเข้า `facescan-ingest`
  - รองรับคำสั่งจากระบบ: `test_connection`, `pull_logs` (ดึงย้อนหลัง N วัน) แล้ว `ack` ผลกลับ
  - log สถานะลงหน้าจอ + กันล้ม (try/catch ต่อเครื่อง, เครื่องนึงพังไม่กระทบเครื่องอื่น)
- `package.json` — ระบุ dependency `node-zklib`, `dotenv` + คำสั่ง `npm start`
- `.env.example` — เทมเพลตให้กรอก Bridge Token + URL
- `README.md` (ภาษาไทย) — ขั้นตอนติดตั้งบน PC แบบ step-by-step:
  1. ลง Node.js
  2. คัดลอกโฟลเดอร์ลง PC
  3. `npm install`
  4. สร้าง `.env` ใส่ Token ที่ได้จากหน้าตั้งค่า
  5. `npm start` (และวิธีตั้งให้รันอัตโนมัติเมื่อเปิดเครื่องด้วย Task Scheduler / pm2)

### 2) ปรับแท็บ "คู่มือ Bridge" ในหน้าตั้งค่า
อัปเดตสคริปต์ตัวอย่างในหน้า `FaceScanConnectionSettings.tsx` จากเวอร์ชัน DLL (koffi) เดิม → ให้ตรงกับโปรแกรม `node-zklib` ตัวจริง พร้อมลิงก์ขั้นตอนติดตั้งให้ชัดเจน

## เรื่อง in/out (เข้า/ออก) ที่ต้องเข้าใจก่อน
เครื่องบางรุ่นไม่ได้ส่งสถานะเข้า/ออกที่เชื่อถือได้ — Bridge จะส่งค่าที่อ่านได้จริงจากเครื่องไปตามตรงก่อน ระบบฝั่ง `facescan-ingest` รับ `in_out` อยู่แล้ว หากเครื่องไม่ส่งสถานะที่ถูกต้อง สามารถเพิ่ม heuristic (เช่น สแกนแรกของวัน = เข้า, สแกนสุดท้าย = ออก) ทีหลังได้ เป้าหมายรอบนี้คือ "ต่อเชื่อมและดึงข้อมูลเข้าได้จริง" ก่อน

## สิ่งที่คุณต้องทำหลังผมสร้างเสร็จ
1. หน้าตั้งค่า → เครื่องสแกน: เพิ่มเครื่องแบบ **โหมด Bridge** ใส่ IP `192.168.2.201`
2. แท็บ Bridge Token: กดสร้าง Token แล้วคัดลอกเก็บไว้
3. คัดลอกโฟลเดอร์ `facescan-bridge/` ไปที่ PC ในออฟฟิศ ใส่ Token ใน `.env` แล้ว `npm start`
4. กด "ทดสอบการเชื่อมต่อ" จากหน้าตั้งค่า — ถ้าเขียว แปลว่า Bridge คุยกับเครื่องและระบบได้แล้ว

## หมายเหตุทางเทคนิค
- โค้ด Bridge เป็นโปรเจกต์ Node.js แยกในโฟลเดอร์ `facescan-bridge/` ไม่กระทบแอปหลัก (ไม่ถูก build/รันโดย Vite)
- หาก port 4370 ถูกปิดที่ตัวเครื่องจริง จะปรับไปลองวิธีอื่น (เช่น โหมด ADMS ที่มี relay พร้อมแล้ว) ได้โดยไม่ต้องรื้อระบบ
