## เป้าหมาย
นำรหัสในเครื่องสแกนหน้า (PIN/Enroll No.) จากไฟล์ Excel มาผูกกับพนักงานในระบบให้ครบทุกคนในครั้งเดียว โดยไม่ต้องกดจับคู่ทีละคน

## สิ่งที่ต้องการจากคุณ
แนบไฟล์ Excel มาในแชท (คอลัมน์ B = รหัส, คอลัมน์ C = ชื่อ+นามสกุล)

## ขั้นตอนที่ผมจะทำ
1. อ่านไฟล์ Excel ทุกแถว ทุกชีต ดึงคู่ (รหัส, ชื่อ-นามสกุล) และตัดแถวว่าง/แถวหัวตารางออก
2. ดึงรายชื่อพนักงานจากฐานข้อมูล (ชื่อ + นามสกุล + ชื่อเล่น) มาเทียบแบบตรงเป๊ะหลังตัดช่องว่างและคำนำหน้า (นาย/นาง/นางสาว) ออก
3. รายการที่จับคู่ได้ → อัปเดตช่องรหัสเครื่องสแกนของพนักงานคนนั้น
4. รายการที่จับคู่ไม่ได้ หรือชื่อซ้ำกันหลายคน หรือรหัสซ้ำ → **ข้าม** และรวมเป็นรายงานให้คุณดู เพื่อแก้เองภายหลัง
5. ตรวจผลหลังนำเข้า: นับว่าพนักงานกี่คนมีรหัสแล้ว กี่คนยังว่าง แล้วสรุปให้คุณ

## รายละเอียดทางเทคนิค
- เขียนสคริปต์อ่านไฟล์ด้วย pandas/openpyxl ในแซนด์บ็อกซ์ ไม่เพิ่มโค้ดถาวรในแอป
- อัปเดตคอลัมน์ `employees.face_scan_id` ผ่านเครื่องมือแก้ไขข้อมูลของฐานข้อมูล (มีขั้นตอนให้คุณกดอนุมัติก่อนรัน)
- ไม่แตะข้อมูลอื่นของพนักงาน และไม่ลบรหัสที่มีอยู่แล้วถ้าไฟล์ไม่มีข้อมูลของคนนั้น
- หลังนำเข้าเสร็จ คุณสามารถกด "ซิงค์รายชื่อไปเครื่อง" ในหน้าตั้งค่า → เครื่องสแกนหน้า ได้ทันที

## ไม่รวมในงานนี้
- ไม่สร้างปุ่มนำเข้าไฟล์ถาวรในหน้าตั้งค่า (ตามที่คุณเลือกให้ผมนำเข้าให้ครั้งเดียว)
- ข้อมูลใบหน้ายังต้องลงทะเบียนที่ตัวเครื่องเหมือนเดิม
