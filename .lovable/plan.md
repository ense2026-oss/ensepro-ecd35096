# ปรับการจัดการแผนก + Dropdown ตำแหน่งงาน

## เป้าหมาย
1. เปลี่ยนคำว่า "สังกัด" เป็น "แผนก" ทั้งหมด (เมนู, ปุ่ม, หัวข้อ, ข้อความ)
2. ทำให้การเลือก/เพิ่มตำแหน่งงานง่ายและไม่ซ้ำซ้อน โดยใช้ระบบ dropdown ที่เลือกจากตำแหน่งที่มีอยู่ได้ และถ้าไม่มีก็พิมพ์เพิ่มใหม่ได้ทันที
3. โครงสร้างยังคงแยกตำแหน่งตามแต่ละแผนกเหมือนเดิม (ไม่แก้ฐานข้อมูล, ไม่แตะการกรองข้อมูล)

## ขอบเขตการเปลี่ยนคำ "สังกัด" → "แผนก"
- เมนูแท็บในหน้า "ตั้งค่า": `จัดการสังกัด` → `จัดการแผนก`
- หน้า `AffiliationSettings`: ปุ่ม `เพิ่มสังกัด` → `เพิ่มแผนก`, ตัวนับ `x สังกัด` → `x แผนก`, หัวข้อ/คำอธิบายใน Dialog, ข้อความ toast, ข้อความยืนยันการลบ และ label ในฟอร์ม
- ฟอร์มพนักงาน (`EmployeeFormDialog`) และหน้าโปรไฟล์: label ที่ยังเขียน "สังกัด" ให้เป็น "แผนก" ให้สอดคล้องกัน

> หมายเหตุ: เปลี่ยนเฉพาะข้อความที่ผู้ใช้เห็น ไม่เปลี่ยนชื่อไฟล์/ตัวแปร/ตาราง (`affiliations`) เพื่อไม่ให้กระทบส่วนอื่น

## ระบบ Dropdown ตำแหน่งงาน (เลือก หรือ เพิ่มใหม่)
สร้าง component ใหม่ `PositionCombobox` (อิงจาก `command` / `popover` ที่มีอยู่) ที่:
- แสดงรายการตำแหน่งที่มีอยู่ของ "แผนก" ที่เลือก
- พิมพ์เพื่อค้นหาได้
- ถ้าพิมพ์ชื่อที่ยังไม่มี จะมีตัวเลือก "➕ เพิ่มตำแหน่ง: <ชื่อ>" เมื่อกดแล้วจะบันทึกตำแหน่งใหม่เข้าแผนกนั้นผ่าน `addPosition` ของ `OrgContext` และเลือกค่านั้นทันที
- ป้องกันการเพิ่มชื่อซ้ำ (กรณีมีอยู่แล้วให้เลือกตัวเดิม)

จุดที่นำไปใช้:
1. **หน้าตั้งค่า "จัดการแผนก"** — Dialog เพิ่มตำแหน่งใช้ combobox แทน input เปล่า เพื่อเลือกตำแหน่งที่เคยใช้ในแผนกอื่นมาใช้ซ้ำได้ และยังเพิ่มใหม่ได้
2. **ฟอร์มเพิ่ม/แก้ไขพนักงาน** (`EmployeeFormDialog`) — ช่อง "ตำแหน่ง" เปลี่ยนจาก `SelectField` เป็น combobox ที่ผูกกับแผนกที่เลือก เพิ่มตำแหน่งใหม่ได้ระหว่างกรอกข้อมูล
3. **หน้าโปรไฟล์พนักงาน** (`EmployeeProfile`) — ช่อง "ตำแหน่ง" ในโหมดแก้ไขเปลี่ยนเป็น combobox เดียวกัน

พฤติกรรมร่วม:
- เมื่อเปลี่ยน "แผนก" ตำแหน่งจะรีเซ็ตและแสดงรายการของแผนกใหม่ (ตามที่มีอยู่แล้ว)
- ตำแหน่งใหม่ที่เพิ่มจากฟอร์มพนักงาน/โปรไฟล์ จะถูกบันทึกเข้าแผนกนั้นในตาราง `positions` ทำให้ครั้งต่อไปเลือกได้เลย ลดการพิมพ์ซ้ำ/พิมพ์ผิด
- ตำแหน่งชื่อเดียวกันสามารถมีได้ในหลายแผนก (เป็นคนละแถวต่อแผนก) — การนับ/กรองตามชื่อยังรวมกันได้เหมือนเดิม และแยกตามแผนกได้เมื่อกรองด้วยแผนก

## รายละเอียดทางเทคนิค
- ใช้ `useOrg()` ที่มีอยู่: `affiliations`, `addPosition(affiliationId, null, name)` สำหรับสร้างตำแหน่งใหม่
- combobox ใช้ `Popover` + `Command` (มีใน `src/components/ui`) จัดสไตล์ตาม design token เดิม
- ใน `EmployeeProfile`/`EmployeeFormDialog` ใช้ helper เดิมที่รวมรายชื่อตำแหน่งของแผนก (`positionOptions`/`filteredPositions`) เป็นแหล่งข้อมูลให้ combobox
- ไม่มีการแก้ schema ฐานข้อมูล และไม่แตะตรรกะการกรองในหน้า `Employees`/`Reports`
