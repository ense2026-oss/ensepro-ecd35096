# FaceScan Bridge

โปรแกรมเล็ก ๆ ที่รันบน **PC ในออฟฟิศ** (เปิดทิ้งไว้) ทำหน้าที่ดึงข้อมูลการสแกนจากเครื่อง
**HIP CiF76S** ผ่านวง LAN เดียวกัน แล้วส่งขึ้นระบบลงเวลาให้อัตโนมัติ

- ไม่ต้องเสียค่าเซิร์ฟเวอร์
- ไม่ต้องเปิดพอร์ตเราเตอร์
- ไม่ต้องแตะ ServerIP เดิมของเครื่อง

```text
[HIP CiF76S 192.168.2.201:4370]
        | LAN (node-zklib)
        v
[Bridge บน PC]  --poll ทุก ~30 วิ-->  ระบบ (Edge Functions)  -->  ตารางลงเวลา
```

---

## ก่อนเริ่ม — เตรียมที่หน้าระบบ

1. เข้า **ตั้งค่า → เชื่อมต่อ FaceScan**
2. แท็บ **เครื่องสแกน** → เพิ่มเครื่อง เลือกโหมด **Bridge** แล้วกรอก
   - **Device IP** = `192.168.2.201` (IP ของเครื่องในวง LAN)
3. แท็บ **Bridge Token** → กด **สร้าง Token** แล้ว **คัดลอกเก็บไว้** (จะแสดงครั้งเดียว)

---

## ติดตั้งบน PC (ทำครั้งเดียว)

1. ติดตั้ง **Node.js เวอร์ชัน 18 ขึ้นไป** จาก https://nodejs.org (เลือก LTS)
2. คัดลอกโฟลเดอร์ `facescan-bridge/` ทั้งโฟลเดอร์มาวางบน PC
3. เปิด **Command Prompt / PowerShell** เข้าไปในโฟลเดอร์ แล้วรัน:
   ```bash
   npm install
   ```
4. สร้างไฟล์ตั้งค่า: คัดลอก `.env.example` เป็น `.env`
   ```bash
   copy .env.example .env       # Windows
   # หรือ
   cp .env.example .env         # macOS/Linux
   ```
5. เปิดไฟล์ `.env` แล้วใส่ **BRIDGE_TOKEN** ที่คัดลอกมาจากหน้าระบบ
   (`FN_BASE` ตั้งค่าให้ถูกต้องไว้แล้ว)

---

## เริ่มใช้งาน

```bash
npm start
```

ถ้าขึ้นข้อความ `FaceScan Bridge เริ่มทำงาน` แปลว่าทำงานแล้ว — Bridge จะ:
- ถามระบบทุก ~30 วินาที เพื่อรับรายชื่อเครื่องและคำสั่งที่ค้างอยู่
- เชื่อมเครื่องที่ IP ที่ตั้งไว้ ดึงเฉพาะรายการสแกน **ใหม่** แล้วส่งขึ้นระบบ
- จำเวลาล่าสุดไว้ในไฟล์ `state.json` (อย่าลบ — ใช้กันส่งข้อมูลซ้ำ)

จากนั้นกลับไปที่หน้าระบบ กด **ทดสอบการเชื่อมต่อ** — ถ้าขึ้นเขียว แปลว่าเชื่อมได้ครบวงจรแล้ว
และลองดึงข้อมูลย้อนหลังได้จากปุ่ม **ดึงข้อมูล** ในหน้าเครื่องสแกน

## ตั้งให้รันอัตโนมัติเมื่อเปิดเครื่อง

### ทางเลือก A — pm2 (แนะนำ)
```bash
npm install -g pm2
pm2 start bridge.js --name facescan-bridge
pm2 save
pm2 startup   # ทำตามคำสั่งที่ขึ้นมาเพื่อให้ start อัตโนมัติหลังรีบูต
```

### ทางเลือก B — Task Scheduler (Windows)
1. เปิด **Task Scheduler** → **Create Basic Task**
2. Trigger: **When the computer starts**
3. Action: **Start a program**
   - Program/script: `node`
   - Arguments: `bridge.js`
   - Start in: เส้นทางโฟลเดอร์ `facescan-bridge`

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ / วิธีแก้ |
|------|------------------|
| `ขาดค่า BRIDGE_TOKEN หรือ FN_BASE` | ยังไม่ได้สร้าง/กรอกไฟล์ `.env` |
| `[poll] ติดต่อระบบไม่ได้` | PC ต่อเน็ตไม่ได้ หรือ Token ผิด/ถูกปิด |
| `[sync] ... ล้มเหลว` (timeout) | PC กับเครื่องไม่อยู่วง LAN เดียวกัน, IP เครื่องผิด, หรือพอร์ต 4370 ถูกปิด |
| Bridge offline ในหน้าทดสอบ | โปรแกรมไม่ได้รันอยู่ / Token ไม่ตรง |

### test_connection ล้มเหลว — อ่านสาเหตุจาก log

ตั้งแต่เวอร์ชันนี้ log จะแสดง **สาเหตุจริง** แทนคำว่า `undefined` แล้ว ให้ดูข้อความท้ายบรรทัด `ล้มเหลว:` แล้วเทียบตามนี้

| ข้อความ error | ความหมาย / วิธีแก้ |
|------|------------------|
| `ECONNREFUSED` | เครื่องตอบ แต่ปฏิเสธพอร์ต 4370 → ไปเปิดบริการ/พอร์ตการสื่อสาร (Comm/TCP) ที่ตัวเครื่อง |
| `ETIMEDOUT` / `TIMEOUT_ON_WRITING_MESSAGE` | ต่อพอร์ตได้แต่เครื่องไม่ตอบโปรโตคอล ZK → ลองเปิดโหมด TCP/ZKAccess บนเครื่อง หรือรีสตาร์ตเครื่องสแกน |
| `EADDRINUSE` | พอร์ต UDP local ชนกัน → เปลี่ยนค่า `ZK_INPORT` ใน `.env` (เช่น `ZK_INPORT=4100`) |
| `EHOSTUNREACH` / `ENETUNREACH` | PC กับเครื่องคนละวง → ตรวจ LAN/IP/Subnet |

> หากพอร์ต `4370` ถูกปิดที่ตัวเครื่อง สามารถลองเปิดในเมนู Comm ของเครื่อง
> หรือเปลี่ยนไปใช้โหมด **ADMS Push** (มี relay พร้อมแล้วในระบบ) แทนได้
